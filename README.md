# CodeIsle · 代码之屿

个人技术站点：Markdown 博客、纯前端开发工具、AI 航路图。

- 仓库：[ltian-code/ltian-code.github.io](https://github.com/ltian-code/ltian-code.github.io)
- 上线后：[https://ltian-code.github.io/](https://ltian-code.github.io/)（GitHub Pages 尚未开启）
- 栈：Nuxt 4 · Vue 3 · Tailwind CSS · Less · Pinia

当前是阶段 3：博客、十个工具、AI 导航都有真实内容。打开 `/`、`/tools`、`/ai`。GitHub Pages 尚未开启。

## 本地开发

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`。

## 静态产出

```bash
npm run generate
```

部署到 GitHub Pages 要等阶段 4 配好 Actions。不要把 `main` 源码直接当作 Pages 站点。
